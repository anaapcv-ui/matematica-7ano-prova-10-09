📅 Como usar este kit

  1. Comece pela Leitura Estendida: leia e responda a fixação de cada estação (é preciso 70% para avançar).
  2. Revise com o Resumo: reforce as regras e vire as cartas de treino.
  3. Faça o Simulado: responda tudo, pegue o código e depois veja o gabarito comentado.
  4. Treine com a Folha de Problemas: resolva mostrando as contas, como na prova de verdade.
  5. Imprima a Folha de Regras para consultar durante os estudos.

👩‍👦 Dica para o responsável

No Simulado, ao terminar, a criança recebe um código de liberação no formato SIM-XX-YY (o XX mostra quantas questões objetivas ela acertou). O gabarito só abre depois de digitar esse código — assim você confere que ela realmente terminou antes de ver as respostas.

A Folha de Problemas tem gabarito travado: o botão "Ver resultado" só libera quando os 5 problemas estão marcados, e mostra apenas acertou/errou (verde = correta; vermelho = a que a criança marcou errada), incentivando ela a mostrar os cálculos.

A questão discursiva do simulado é corrigida por você com a resposta modelo que aparece no gabarito.
